A production-oriented Java backend Order Management System exploring REST APIs, PostgreSQL, testing, concurrency, system design, and scalable architecture.

## Goals

- Deepen Core Java
- Build production-quality backend services
- Practice object-oriented design
- Learn backend testing
- Understand concurrency
- Build REST APIs
- Work with PostgreSQL
- Practice system design
- Transition into Spring Boot
- Develop SDE2-level engineering habits
